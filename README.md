## 게임 소개

Necromancer Survivors는 지속적으로 몰려오는 적을 상대하며 생존하는 Vampire Survivors-like 액션 게임입니다.

3개 스테이지에 스테이지별 최종 보스와 무작위 배치 함정을 더했습니다.
